# Hello World

这是我的第一个 GitHub 仓库，用来练习 Git 与 GitHub 的基本流程。

创建时间：2026-11-05

## 项目简介

一个用 Python 写的命令行「猜数字」小游戏：程序随机生成 1~100 的整数，
你不断输入数字，程序提示「大了」或「小了」，直到猜中为止。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `hello.py` | 游戏主程序 |
| `.gitignore` | 告诉 Git 哪些文件不用上传（如缓存） |
| `README.md` | 项目说明书，就是你现在看的这个 |

## 如何运行

需要先装好 Python（3.8 以上）。在本文件夹打开终端，执行：

```bash
python hello.py
```

然后按提示输入数字即可。输入 `q` 退出。
